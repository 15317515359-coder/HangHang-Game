# 🎮 游戏玩法指南

## 游戏概述

**HangHang-Game** 是一款休闲农场模拟游戏，融合策略、经营和社交元素。玩家需要管理自己的农场，与 NPC 互动，完成各类任务以获得收益。

## 核心玩法机制

### 1. 🌾 农业系统

#### 作物种植
- **选择作物:** 不同季节有不同的作物
- **购买种子:** 从商人或 NPC 购买种子
- **整地:** 准备农田，增加土壤肥力
- **灌溉:** 定期给作物浇水
- **收获:** 等待作物成熟后收获

#### 作物类型

| 作物 | 季节 | 生长期 | 产值 | 备注 |
|------|------|--------|------|------|
| 萝卜 | 春季 | 4天 | 50金 | 初学者友好 |
| 玉米 | 夏季 | 7天 | 120金 | 需要大量水分 |
| 南瓜 | 秋季 | 10天 | 180金 | 高产值 |
| 冬小麦 | 冬季 | 6天 | 80金 | 抗冷 |
| 黄金稻 | 夏季 | 14天 | 300金 | 稀有作物 |

#### 土壤管理
```
土壤肥力等级:
- 贫瘠（0-30%）：作物生长缓慢 -50% 效率
- 一般（30-60%）：正常生长速度
- 肥沃（60-100%）：加快生长 +30% 效率

提升方法:
- 施肥：使用化肥或有机肥（+15% 肥力）
- 轮作：改变种植的作物类型（+10% 肥力）
- 堆肥：收集动物粪便制作堆肥（+20% 肥力）
```

### 2. 💼 经济系统

#### 资源管理
- **金币:** 主要货币，用于购买物品和升级
- **工业点:** 通过制作物品获得
- **声望:** 通过完成任务和与 NPC 互动获得

#### 交易

**商人摊位:**
- 每天刷新不同的商品
- 价格随供需波动
- 可以讨价还价（需要声望）

**NPC 交易:**
- 与特定 NPC 建立关系后解锁特殊交易
- 完成任务获得特殊物品
- 参与限时交易活动

#### 价格系统
```
动态价格计算：
基础价格 × (0.8 + 供应量系数 × 0.4)

- 供应充足：价格下降 -40%
- 供应平衡：价格正常
- 供应紧张：价格上升 +40%
```

### 3. 👥 社交系统

#### NPC 类型

**商人:**
- 销售种子、工具、物品
- 可以收购你的农产品
- 参与竞拍活动

**村民:**
- 可以结为好友
- 接受任务
- 参与节日活动

**特殊 NPC:**
- 任务给予者
- 制作师傅
- 魔法师

#### 好感度系统

```
好感度等级：
- 陌生人 (0-20%)：基础互动
- 熟人 (20-40%)：接收任务
- 朋友 (40-60%)：特殊对话
- 好友 (60-80%)：节日邀请
- 知心 (80-100%)：特殊活动解锁

提升方法：
- 赠送喜爱的物品 (+5% 好感度)
- 完成任务 (+10% 好感度)
- 参与节日活动 (+15% 好感度)
- 日常对话 (+1% 好感度)
```

#### 任务系统

**主线任务:**
- 推动故事发展
- 必须完成以解锁内容
- 提供主要收益

**支线任务:**
- 由 NPC 提供
- 可选完成
- 获得额外奖励和好感度

**日常任务:**
- 每天刷新
- 快速完成赚取金币
- 适合新手

### 4. 🏗️ 建筑系统

#### 建筑类型

**功能建筑:**
- **谷仓:** 存储农产品
- **工作坊:** 制作物品
- **养殖场:** 饲养动物
- **温室:** 种植特殊作物

**装饰建筑:**
- **亭子:** 增加美观度
- **喷泉:** 提升村庄魅力
- **花圃:** 吸引蜜蜂
- **雕像:** 彰显个性

#### 建筑升级

```
升级流程：
1. 收集升级材料
2. 支付升级费用
3. 等待升级时间
4. 解锁新功能

示例 - 谷仓升级：
等级 1: 容量 500
等级 2: 容量 800 + 温度控制
等级 3: 容量 1200 + 防虫系统
等级 4: 容量 2000 + 自动分类
```

### 5. 📦 制作系统

#### 工作坊制作

**需要的资源:**
- 原料
- 时间
- 工具（可选）

**常见制作:**

| 物品 | 材料 | 时间 | 产值 |
|------|------|------|------|
| 番茄酱 | 番茄×5 | 2小时 | 100金 |
| 面粉 | 小麦×3 | 1小时 | 60金 |
| 奶酪 | 牛奶×2 | 4小时 | 150金 |
| 果酒 | 浆果×5 | 8小时 | 200金 |

#### 工具制作

**升级工具:**
- 铜锄 → 银锄 → 金锄
- 提高效率和耐久度
- 解锁新的农作区域

## 特殊系统

### 季节系统

**春季（1-30 天）:**
- 种植春季作物
- 天气多变
- 举办春季集市

**夏季（31-60 天）:**
- 高温天气
- 需要更多灌溉
- 夏季节日

**秋季（61-90 天）:**
- 收获季节
- 丰收活动
- 准备过冬

**冬季（91-120 天）:**
- 低温天气
- 限定作物
- 室内活动增多

### 天气系统

```
天气类型：
- 晴天：正常条件
- 多云：稍微减慢作物生长
- 雨天：自动灌溉，提升土壤肥力
- 暴雨：可能损害作物
- 雪天：只能进行室内活动
```

### 事件系统

**随机事件:**
- 害虫入侵
- 意外收获
- NPC 访问
- 商人打折

**节日活动:**
- 春季花展
- 夏季烟火节
- 秋季丰收节
- 冬季圣诞节
